## Overview

### Experiment 1: E-commerce ER Diagram
Design an entity-relationship diagram for an e-commerce database and identify its entities and relationships.

### Experiment 2: Relational Schema and Constraints
Convert the database design into relational tables and define suitable keys and constraints.

### Experiment 3: SQL Queries and Aggregate Functions
Practice SQL queries using filtering, sorting, aggregate functions, and grouping.

### Experiment 4: Joins, Subqueries and EXPLAIN
Work with joins and subqueries, and inspect query execution information using `EXPLAIN`.

### Experiment 5: Views and Recursive CTE
Create views and use recursive common table expressions where applicable.

### Experiment 6: Stored Procedures, Triggers and Audit Logging
Explore stored procedures, triggers, and audit logging for database operations.

### Experiment 7: Database Normalization
Study normalization and organize relational data to reduce redundancy and improve consistency.

### Experiment 8: Transactions and Concurrency
Explore transaction handling and concepts related to concurrent database operations.

### Experiment 9: Indexing and Performance
Study indexes and their role in query performance.

### Experiment 10: Query Optimization
Examine query execution and optimization techniques.
