## How to Use

1. Open the required `.sql` file in a MySQL-compatible SQL editor, such as the ByteXL MySQL editor.
2. Run the SQL statements and review the results.
3. Refer to the matching `-Output.txt` file for the recorded output.

**Important:** Some experiment scripts create or drop tables. Run them in a separate practice database/session if you need to preserve data from another experiment.
