## How to Run

1. Open the required `.sql` file in a MySQL-compatible editor, such as the ByteXL MySQL editor.
2. Run the SQL statements and review the results.
3. Open the corresponding output file to review the recorded results.

## Important Notes

- Experiments 1 and 2 are uploaded as PDF files.
- Experiments 3 to 6 have separate SQL source-code files and output text files.
- Some SQL scripts drop and recreate tables. Run them in a separate practice database/session if you need to preserve data from another experiment.
- The `.txt` output files are formatted records of the results observed during execution. Keep screenshots from the SQL editor as additional evidence if your instructor requires them.
