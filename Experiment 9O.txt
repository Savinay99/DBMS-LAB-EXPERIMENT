7. INDEX VERIFICATION

The SHOW INDEX FROM RailwayBooking query was executed to inspect the indexes created on the table, including the primary key and the train-number and composite indexes.

RESULT:
A RailwayBooking table containing 5,120 records was created. EXPLAIN showed a full table scan before the TrainNumber index was added and use of the idx_trainnumber index afterward. The composite index was also created and the filtered booking query was executed.

NOTE:
The full filtered query output is intentionally not reproduced because it contains a large number of rows. The sample above represents the first records shown in the ByteXL output. Query-plan estimates can vary depending on the MySQL optimizer and statistics.
